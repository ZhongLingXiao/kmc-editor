# 动画对齐编辑器

用于编辑游戏角色动画的精灵对齐、碰撞箱、发射点等数据，输出 JSON 供游戏引擎使用。

## 快速开始

```bash
cd animation-editor
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`

## 功能

### 帧管理
- 添加帧、删除帧、复制帧
- 为每帧载入精灵图（PNG）
- 设置每帧停留时长（Tick 数）

### 精灵对齐
- 设置每帧精灵轴点（Sprite Pivot），与固定角色根点 `Root (0,0)` 对齐
- 快速设置轴点：脚底中心 / 图片中心
- 显示图片局部原点 `Image (0,0)` 与不可编辑的角色根点 `Root (0,0)`
- 洋葱皮预览（前后帧半透明叠加）

### 碰撞箱
- 绘制 Hurtbox（受击框，蓝色）
- 绘制 Hitbox（攻击框，红色）
- 绘制 Pushbox（推挤框，绿色）
- 拖拽移动、Transformer 缩放
- 数值精确输入

### 发射点
- 放置命名发射点（如 sword_tip, hand_left）
- 拖拽调整位置
- 命名管理

### 预览
- 播放/暂停（空格键）
- 逐帧切换（← →键）
- 播放速度调节（0.25x ~ 2x）
- 循环播放

### 撤销/重做
- Ctrl+Z 撤销
- Ctrl+Y / Ctrl+Shift+Z 重做
- 最多 100 步历史

### 导入/导出
- 导出动画数据为 JSON 文件
- 导入 JSON 继续编辑

## 画布操作

| 操作 | 方式 |
|------|------|
| 选择工具 | 点击工具栏"选择" |
| 绘制受击框 | 选"受击框"工具，画布拖拽 |
| 绘制攻击框 | 选"攻击框"工具，画布拖拽 |
| 放置发射点 | 选"发射点"工具，点击画布 |
| 设置锚点 | 选"锚点"工具，点击精灵图 |
| 缩放画布 | 鼠标滚轮 |
| 移动碰撞箱 | 选择工具下拖拽 |
| 缩放碰撞箱 | 选中后拖拽 Transformer 手柄 |

## 坐标系

- **逻辑坐标**：角色锚点为原点 (0,0)，Y 向上为正
- **屏幕坐标**：画布左上角为原点 (0,0)，Y 向下为正
- 所有导出数据使用逻辑坐标

## 导出格式

```json
{
  "id": "anim_200",
  "name": "5A 站立轻拳",
  "version": "1.0",
  "totalTicks": 15,
  "loop": false,
  "elements": [
    {
      "index": 0,
      "sprite": { "src": "frame_0.png", "w": 45, "h": 60 },
      "duration": 3,
      "offset": { "x": 22, "y": 60 },
      "hurtboxes": [{ "id": "xxx", "x": -15, "y": 0, "w": 30, "h": 55 }],
      "hitboxes": [],
      "spawnPoints": []
    }
  ],
  "pushbox": {
    "stand": { "id": "push_stand", "x": -12, "y": 0, "w": 24, "h": 60 }
  }
}
```

## 技术栈

- React 18 + TypeScript
- Konva / react-konva（画布渲染）
- Zustand + zundo（状态管理 + 撤销重做）
- Vite（构建工具）
