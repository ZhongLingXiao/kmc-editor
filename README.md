# 动画对齐编辑器

用于编辑游戏角色动画的精灵对齐、碰撞箱、发射点等数据，输出 JSON 供游戏引擎使用。

## 快速开始

```bash
cd animation-editor
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`

## 功能

### 帧管理
- 添加帧、删除帧、复制帧
- 为每帧载入精灵图（PNG）
- 设置每帧停留时长（Tick 数）
- 在时间线上标定前摇、攻击判定、后摇，并按 Tick 精确调整边界

### 精灵对齐
- 设置每帧精灵轴点（Sprite Pivot），与固定角色根点 `Root (0,0)` 对齐
- 拖拽精灵移动；按住 Shift 拖拽锁定主轴向（水平/垂直）
- 方向键微调轴点（Shift+方向键 10px）
- 快速设置轴点：脚底中心 / 图片中心
- 显示图片局部原点 `Image (0,0)` 与不可编辑的角色根点 `Root (0,0)`
- 洋葱皮预览（前后帧半透明叠加）

### 碰撞箱
- 绘制 Hurtbox（受击框，蓝色）
- 绘制 Hitbox（攻击框，红色）
- 绘制 JC Box（判定框，紫色，可用于弹反/精确判定）
- 绘制 Pushbox（推挤框，绿色）
- 拖拽移动、Transformer 缩放
- 拖拽时按住 Shift 锁定主轴向（水平/垂直）
- 选中后方向键微调位置（Shift+方向键 10px）
- 数值精确输入

### 发射点
- 放置命名发射点（如 sword_tip, hand_left）
- 拖拽调整位置
- 命名管理

### 预览
- 播放/暂停（空格键）
- 逐帧切换（← →键）
- 播放速度调节（0.25x ~ 2x）
- 循环播放

### 撤销/重做
- Ctrl+Z 撤销
- Ctrl+Y / Ctrl+Shift+Z 重做
- 最多 100 步历史

### 导入/导出
- 导出动画数据为 JSON 文件
- 导入 JSON 继续编辑

## 工程化文件系统

编辑器采用**工程目录**模型（类似 Maya project）：一个工程 = 一个文件夹 = 一个动画，所有资源按相对路径组织，工程目录始终自洽，可整体拷贝或交给游戏引擎导入。

### 工程目录结构

```
hero_stand/                    工程根（一个文件夹 = 一个动画）
├── anim_200.json              动画数据，sprite.src 为相对工程根的路径
└── sprites/
    └── stand/                按动画名 slug 命名
        ├── frame_0.png
        ├── frame_1.png
        └── frame_2.png
```

### 工作流

1. **新建/打开工程**：菜单「工程」→「新建工程…」/「打开工程…」，选择一个文件夹作为工程根（需 Chromium 系浏览器，如 Chrome/Edge）
2. **导入图片**：在帧列表/画布拖入或「载入图」选择 PNG，图片会自动复制到工程目录的 `sprites/<动画名>/` 下；若图片已在工程目录内则直接引用相对路径，不重复拷贝
3. **多帧共用图片**：复制帧/继承帧会复用源帧的 `src`，磁盘上只有一份文件
4. **保存**：Ctrl+S 将动画 JSON 写入工程根的 `<动画id>.json`
5. **跨会话恢复**：工程目录句柄持久化在 IndexedDB，下次打开浏览器自动恢复（首次需重新授权）

### 旧 base64 文件兼容

打开/导入旧格式 JSON（含内嵌 base64 图片）时，若已打开工程会自动把图片迁移到工程目录并替换为相对路径；若未打开工程会提示先创建/打开工程再导入。

### 浏览器要求

File System Access API 仅 Chromium 系支持（Chrome/Edge）。Firefox/Safari 不支持目录句柄，仅能使用「文件」菜单的导入/导出 JSON（不含工程目录功能）。

## 坐标系

- **逻辑坐标**：角色锚点为原点 (0,0)，Y 向上为正
- **屏幕坐标**：画布左上角为原点 (0,0)，Y 向下为正
- 所有导出数据使用逻辑坐标

## 导出格式

```json
{
  "id": "anim_200",
  "name": "5A 站立轻拳",
  "version": "1.0",
  "totalTicks": 15,
  "loop": false,
  "elements": [
    {
      "index": 0,
      "sprite": { "src": "sprites/stand/frame_0.png", "w": 45, "h": 60 },
      "duration": 3,
      "offset": { "x": 22, "y": 60 },
      "hurtboxes": [{ "id": "xxx", "x": -15, "y": 0, "w": 30, "h": 55 }],
      "hitboxes": [],
      "spawnPoints": []
    }
  ],
  "phases": {
    "activeStartTick": 4,
    "activeEndTick": 7
  },
  "pushbox": {
    "stand": { "id": "push_stand", "x": -12, "y": 0, "w": 24, "h": 60 }
  }
}
```

`phases` 可选，使用左闭右开 Tick 区间：前摇为 `[0, activeStartTick)`，
攻击判定为 `[activeStartTick, activeEndTick)`，后摇为
`[activeEndTick, totalTicks)`。它是动画数据的一部分，即使关闭编辑器元数据导出也会保留。

## 技术栈

- React 18 + TypeScript
- Konva / react-konva（画布渲染）
- Zustand + zundo（状态管理 + 撤销重做）
- Vite（构建工具）
